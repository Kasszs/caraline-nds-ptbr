🗝️ Como Funciona por Dentro (De Forma Bem Humana)

Você já teve curiosidade de saber como um jogo antigo de Nintendo DS guarda as suas falas e como uma tradução é colocada dentro dele? Aqui está a história real dos bastidores:

📁

1. Onde as falas moram?

Dentro da ROM existem 38 arquivos que começam com o nome eve_*.bin (de *evento*). Cada cômodo da mansão (o banheiro, a sala da Outra Mãe, o jardim misterioso) tem um arquivo próprio. Dentro de cada um, as falas de todos os idiomas ficam empilhadas como andares de um prédio. Nós colocamos nosso Português no lugar do Inglês!

⚡

2. O Mistério dos Acentos (ARM9)

No início, ao digitar palavras como "coração" ou "você", o jogo mostrava símbolos japoneses quebrados (ﾃｩ). O executável do DS ignorava acentos no modo inglês. Descobrimos que trocando um único byte no endereço 0x0E04 (de 0x02 para 0x01), o jogo ativa o decodificador UTF-8 nativo e libera todos os nossos acentos!

📏

3. A Telinha e os Limites

A tela do Nintendo DS é bem pequena (apenas 256 por 192 pixels!). A caixa de diálogo só suporta frases com no máximo 140 pixels de largura e até 3 linhas por fala. Se passar disso, a fala corta na metade. Por isso, criamos um simulador que mede cada letrinha antes de enviar para o jogo.

🎨

4. As Texturas (NITRO 2D)

Nem tudo é texto puro: avisos como "Touch the Screen" são desenhos armazenados no formato Nitro (.NCGR com paleta .NCLR). Criamos uma ferramenta que transforma esses dados em arquivos PNG comuns, para podermos traduzir a arte no Photoshop e colocar de volta no jogo sem perder qualidade!

🚀 Como Aplicar no Seu Próprio Jogo

Se você tem uma cópia do jogo Coraline em formato .NDS, veja como é simples jogar com a nossa tradução:

1

Baixe o Repositório

Clone ou baixe o repositório caraline-nds-ptbr pelo GitHub na sua máquina.

2

Descompacte a ROM

Use o programa dslazy ou ndstool para extrair os arquivos da ROM original de Coraline para uma pasta chamada NDS_UNPACK.

3

Injete Tudo com 1 Comando

Execute no terminal: python aplicar_traducao.py. O script copiará os 38 arquivos traduzidos, as texturas, os nomes dos itens e aplicará o patch dos acentos automaticamente.

4

Recompile e Divirta-se!

Pelo dslazy, clique no botão NDS BUILD para gerar sua nova ROM (.nds) com a história inteira de Coraline em bom português!
